# S2-02 — PDF Generator

**Sprint:** 2 | **Effort:** M | **Status:** upcoming

## Description
Render a tailored resume dict into a polished, ATS-friendly PDF using reportlab + jinja2. Single-column clean layout with consistent typography.

## Acceptance Criteria
- [ ] `PDFGenerator` class in `src/pdf_generator.py`
- [ ] `generate(resume, output_path)` method produces a valid PDF file
- [ ] Sections rendered: personal header, summary, experience, education, skills
- [ ] ATS-friendly: no tables, no columns, no images — plain text flow
- [ ] Font: Helvetica or similar system font (no external font dependencies)
- [ ] Page margins respected, no content overflow
- [ ] CLI: `python src/pdf_generator.py resume.json output.pdf`
- [ ] Unit tests: PDF file is created, non-zero size, correct path

## Notes
- Use reportlab's Platypus for structured layout
- Skills rendered as comma-separated line, not a grid

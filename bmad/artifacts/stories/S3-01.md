# S3-01 — Application Tracker

**Sprint:** 3 | **Effort:** S | **Status:** upcoming

## Description
SQLite-based tracker to log every job application and its status. Persists URL, company, title, score, applied date, and current status.

## Acceptance Criteria
- [ ] `ApplicationTracker` class in `src/tracker.py`
- [ ] `log(url, jd, match_result, dry_run)` — inserts a new application record
- [ ] `update_status(url, status)` — updates application status (applied/interview/rejected/offer)
- [ ] `list_applications()` — returns all records as list of dicts
- [ ] SQLite DB created at `jobber.db` (path configurable via env `JOBBER_DB`)
- [ ] CLI: `python src/tracker.py list` / `python src/tracker.py update <url> <status>`
- [ ] Unit tests covering log, update, list, and DB creation

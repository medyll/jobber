# S2-01 — Resume Tailor

**Sprint:** 2 | **Effort:** M | **Status:** upcoming

## Description
Use Ollama LLM to rewrite resume sections (summary, experience bullets) to better target a specific job description. Takes the parsed resume + match result as input, returns a tailored resume dict.

## Acceptance Criteria
- [ ] `ResumeTailor` class in `src/tailor.py`
- [ ] `tailor(resume, jd, match_result)` method returns modified resume dict
- [ ] Rewrites `summary` section to reflect JD keywords and tone
- [ ] Rewrites top experience bullet points to emphasize matched skills
- [ ] Falls back gracefully if Ollama unavailable (returns original resume unchanged)
- [ ] CLI: `python src/tailor.py resume.json jd.json match.json`
- [ ] Unit tests covering rewrite logic and fallback path

## Notes
- Keep rewrites factually grounded — no hallucinated experience
- Prompt should instruct model to preserve dates, company names, and facts

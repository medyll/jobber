# S3-02 — Pipeline Entrypoint

**Sprint:** 3 | **Effort:** M | **Status:** upcoming

## Description
`main.py` wires all modules into a single end-to-end command: parse resume → scrape JD → match → tailor → generate PDF → apply → track.

## Acceptance Criteria
- [ ] `src/main.py` with `run(resume_path, jd_url, dry_run=True)` function
- [ ] Orchestrates: ResumeParser → JDAnalyzer → SemanticMatcher → ResumeTailor → PDFGenerator → ApplyBot → ApplicationTracker
- [ ] Prints a summary report at the end (score, fields filled, PDF path, tracker status)
- [ ] Each step is skippable via flags: `--skip-apply`, `--skip-tailor`, `--skip-pdf`
- [ ] CLI: `python src/main.py resume.pdf https://example.com/job [--live] [--skip-apply]`
- [ ] Unit tests: pipeline runs end-to-end with all modules monkeypatched

# S2-03 — Auto-Apply Bot

**Sprint:** 2 | **Effort:** L | **Status:** upcoming

## Description
Playwright-based bot that fills and submits job application forms. Supports LinkedIn Easy Apply and generic web forms. Dry-run mode by default (fills but does not submit).

## Acceptance Criteria
- [ ] `ApplyBot` class in `src/apply_bot.py`
- [ ] `apply(url, resume, dry_run=True)` method navigates to URL and fills the form
- [ ] Dry-run mode: fills fields, screenshots the form, does NOT click submit
- [ ] Live mode: fills and submits (requires `dry_run=False` explicit opt-in)
- [ ] Fills: name, email, phone, resume upload (PDF path), cover letter (optional)
- [ ] Saves screenshot to `bmad/artifacts/screenshots/apply-<timestamp>.png`
- [ ] Returns result dict: `{success, url, fields_filled, screenshot_path}`
- [ ] CLI: `python src/apply_bot.py <url> <resume.json> <resume.pdf> [--live]`
- [ ] Unit tests: dry-run mode with monkeypatched Playwright, result dict shape

## Notes
- Default is always dry_run=True — user must explicitly pass --live
- LinkedIn Easy Apply requires Playwright (JS-rendered)
- Generic forms use CSS selectors: input[name*="email"], input[name*="phone"], etc.
